# MineDock v0.1.2

## 中文

- 上一页和下一页统一为对称图标，增加当前页、总页数、页码跳转和输入检查。
- 放大页码并修复文字遮挡；搜索、加载失败、空结果和末页变化均有对应处理。
- 关联 PCL 或 HMCL 后自动选择对应游戏目录；兼容 PCL 便携路径及 HMCL 新旧隔离、自定义运行目录与继承设置。
- 选中侧栏与结果行带轻微上浮、柔和阴影和强调标记；按钮有悬停与按下反馈，点击区域保持稳定。
- 改善最小窗口布局，修复缩窄窗口后结果行右侧裁切。
- 更新中英 README、启动器兼容说明、验证记录和可重复运行的检查项目。

验证：55 项界面检查、92 项核心与启动器检查、20 项背景回归及 5 项便携程序启动检查通过。HMCL 配置兼容使用官方源码与配置样例核对，并检查官方 3.16.4 EXE / JAR 的识别。尚未完成真实 PCL / HMCL 启动游戏验证，本次未重复完整游戏安装。

下载便携 ZIP，解压后运行 `MineDock/MineDock.exe`，无需额外安装 .NET。Windows 10 / 11 x64，当前仅在 Windows 11 实机检查。完整源码、许可、验证记录随源码 ZIP 提供；`SHA256SUMS.txt` 给出两份 ZIP 的 SHA-256。

本项目完全源于许愿式编程，开发者在相关知识方面几乎是纯小白。

## English

- Match the previous and next icons and add current / total pages, page jumps, and input validation.
- Enlarge page numbers and fix clipped text, with handling for new searches, failed requests, empty results, and changing final pages.
- Automatically select the game directory after associating PCL or HMCL. Support PCL portable paths and legacy / current HMCL isolation, custom run directories, and inheritance.
- Raise selected navigation and result rows with soft shadows and accent markers. Add hover / pressed feedback while preserving stable button hit targets.
- Improve minimum-window layout and prevent result rows from being clipped after resizing.
- Update bilingual READMEs, launcher compatibility notes, validation records, and repeatable checks.

Validation: 55 UI checks, 92 core / launcher checks, 20 background regression checks, and 5 portable startup checks passed. HMCL configuration behavior was checked against official source code and configuration fixtures; official 3.16.4 EXE / JAR identity detection was also checked. Launching the game through PCL / HMCL has not been verified, and the full game installation was not repeated.

Extract the portable ZIP and run `MineDock/MineDock.exe`; the .NET runtime is included. Targets Windows 10 / 11 x64; tested on Windows 11 only. The source ZIP includes the source, licenses, and validation records. `SHA256SUMS.txt` contains SHA-256 hashes for both archives.

This project was created entirely through "wish-driven programming" with an AI coding assistant. The developer is almost a complete beginner in the relevant fields.
