# MineDock v0.1.4

## 中文

- 修复仅有 Fabric 及版本选择不完整的问题，提供 Forge、NeoForge、Fabric、Quilt、OptiFine、Legacy Fabric、LiteLoader 的兼容版本列表，保留预发布。
- 加入 Minecraft 快照及历史 Alpha / Beta 筛选；切换游戏或加载器时取消旧请求，无兼容版本和联网失败分别提示。
- 实际安装启动配置、支持库与所需处理产物，失败或取消回滚；修复历史原生库、ASM 地址及 LiteLoader 快照解析。
- 从 `EnchantGapple233/Minedock` 正式 GitHub Releases 自动检查新版本，核对大小和 SHA-256 后在空闲时替换、重启，失败恢复原程序。标题栏可手动检查或关闭自动更新。
- 修复更新菜单在明暗主题下的文字和背景对比度；游戏页区分加载中、获取失败与筛选为空，切换来源自动重试，并提供显示全部版本入口。
- 增加标题栏界面刷新入口，重新扫描本地版本并刷新当前栏目，保留筛选、页码及游戏安装选择。
- 首屏显示后先在后台预加载分类及四个资源栏目的第一页，再加载每栏最多 6 个图标，避免慢图标拖延列表；复用已有缓存和进行中的请求，不改变当前页面，不自动下载游戏、模组文件或 Java。

对应问题：[Issue #1](https://github.com/EnchantGapple233/Minedock/issues/1)。

加载器只列出上游实际发布的兼容版本，不代表每个 Minecraft 版本都能安装每种加载器。Forge / NeoForge / OptiFine / LiteLoader 使用随附、未经修改的 HMCL 3.16.4 引擎，需 JDK 21 或游戏要求的更高版本；缺少时加入安装计划。安装处理阶段仍可能联网获取依赖，额外下载量不包含在初始计划大小中。

账号登录与游戏启动继续由 PCL / HMCL 负责。本次验证真实安装配置和支持库，未登录账号或启动游戏，也未在 Windows 10 实机验证。详细范围见 [VALIDATION.md](../../VALIDATION.md)。

直接运行 `MineDock.exe`，或解压 `MineDock-0.1.4-win-x64.zip` 后运行其中的同一文件，无需额外安装 .NET。`MineDock-0.1.4-source.zip` 包含项目源码、内置启动器、原始许可及 HMCL / HMCLauncher 对应源码。

## English

- Fix the Fabric-only selection and incomplete version lists. Offer compatible Forge, NeoForge, Fabric, Quilt, OptiFine, Legacy Fabric, and LiteLoader releases, including previews.
- Include Minecraft snapshots and historical Alpha / Beta filters. Cancel stale requests and distinguish unavailable versions from network failures.
- Install launch profiles, libraries, and required processing outputs with cancellation and rollback. Fix historical native classifiers, ASM URLs, and LiteLoader snapshot resolution.
- Check stable GitHub Releases from `EnchantGapple233/Minedock`, verify size and SHA-256, and replace and restart when idle, restoring the original program on failure. Offer manual checks and an automatic-update switch.
- Fix update-menu contrast in both themes. Distinguish game-list loading, fetch failures, and empty filters; reload on source changes and offer to clear filters.
- Add a title-bar interface refresh action that rescans local versions and refreshes the current section while preserving filters, pagination, and game-installation choices.
- After the initial view appears, preload tags and four resource first pages before fetching up to six icons per section, so slow icons do not delay lists. Reuse fresh caches and pending requests without changing the current page or downloading game payloads, mod files, or Java.

Tracked by [Issue #1](https://github.com/EnchantGapple233/Minedock/issues/1).

Lists reflect releases available for the selected game; every loader is not available for every Minecraft version. Forge, NeoForge, OptiFine, and LiteLoader use the bundled, unmodified HMCL 3.16.4 engine. The plan includes JDK 21 or a higher game requirement when needed. Processing may download additional dependencies beyond the initial plan size.

Authentication and game launching remain the responsibility of PCL / HMCL. Validation covers real installed profiles and libraries, without logging in or starting the game. Windows 10 was not tested on a physical machine. See [VALIDATION.md](../../VALIDATION.md).

Run `MineDock.exe` directly or extract `MineDock-0.1.4-win-x64.zip` and run the same file. No separate .NET installation is required. `MineDock-0.1.4-source.zip` includes project sources, bundled launchers, original licenses, and corresponding HMCL / HMCLauncher source.
