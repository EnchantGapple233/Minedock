# MineDock v0.1.3

## 中文

- 从 MineDock 直接打开已关联的 PCL / HMCL，支持 EXE 及 HMCL JAR。
- 内置原样的 PCL 2.99.0.0、HMCL 3.16.4 官方 EXE，可选择目录、离线安装并自动关联对应 `.minecraft`。
- 对已有不同版本保留原文件，相同版本直接复用；安装包含大小、SHA-256、身份校验及取消清理。
- 提供 Windows x64 单 EXE，自带 .NET 运行时、原生组件和启动器。首次启动会自动展开运行组件到缓存目录。
- 在程序内查看完整许可，并离线导出 HMCL 与其 Windows 包装器 HMCLauncher 的对应源码及构建脚本。
- 选项与结果行悬停时轻微上浮并显示阴影，移开后落下；点击选中变色，按下有回落反馈。
- 四个 Modrinth 栏目分别缓存，返回时恢复筛选、页码、选择与滚动位置；列表可跨重启保留 24 小时，支持手动刷新。
- 缓存过期、损坏或无法写入时保持可用；新目标重新筛选，快速切换时旧响应不覆盖新栏目。

HMCL JAR 需要 Java 17 或更高版本。账号登录、游戏启动与模组管理继续由启动器处理。Windows 10 尚未实机验证。

直接下载 `MineDock.exe` 即可运行，或解压 `MineDock-0.1.3-win-x64.zip` 后运行其中的同一文件，无需额外安装 .NET。完整源码、内置启动器、许可和 HMCL / HMCLauncher 对应源码包含在 `MineDock-0.1.3-source.zip` 中，`SHA256SUMS.txt` 提供三个下载文件的 SHA-256。

141 项界面与启动器检查通过，既有 92 项核心检查及 20 项背景回归检查也已通过。最终单 EXE 已独立检查在线列表、图标、分页恢复与正常退出；两份内置启动器的窗口启动、安装和许可窗口在首次 0.1.3 候选版中验证。未验证从启动器登录并启动游戏，也未重复完整游戏安装。HMCL 首次运行仍可能需要联网获取 Java / JavaFX。

## English

- Open the associated PCL / HMCL from MineDock, with EXE and HMCL JAR support.
- Install the bundled, unmodified official PCL 2.99.0.0 and HMCL 3.16.4 EXEs offline, choose a directory, and associate the neighboring `.minecraft` automatically.
- Preserve different existing launchers, reuse identical files, and verify payload size, SHA-256, and identity, with cancellation cleanup.
- Provide a self-contained Windows x64 single EXE including .NET, native components, and the launchers. Runtime components are automatically extracted into a cache on first launch.
- View component licenses and export complete corresponding HMCL / HMCLauncher source archives and build scripts offline.
- Raise options and result rows with shadows on hover, return them to rest on pointer leave, and preserve selected colors with pressed feedback.
- Cache the four Modrinth sections independently, restoring filters, pages, selection, and scrolling. Persist lists for 24 hours across restarts, with manual refresh available.
- Remain usable with corrupt, expired, or unwritable caches; reapply filters for changed targets and reject late responses from another section.

HMCL JAR files need Java 17 or later. Authentication, the game process, and mod management remain the launcher's responsibility. Windows 10 has not been tested on a physical machine.

Run the direct `MineDock.exe` download, or extract `MineDock-0.1.3-win-x64.zip` and run the same file. No separate .NET installation is required. `MineDock-0.1.3-source.zip` contains complete project sources, bundled launchers, licenses, and corresponding HMCL / HMCLauncher source. `SHA256SUMS.txt` provides hashes for all three downloads.

Passed 141 UI / launcher checks; the existing 92 core checks and 20 background regression checks also passed. The final single EXE was checked independently with live lists, icons, page restoration, and normal exit. Both bundled launcher windows, the installer, and license notices were checked on the initial 0.1.3 candidate. Authentication and game launching through these launchers have not been verified, and the full game installation was not repeated. HMCL may obtain Java / JavaFX online on its first run.
